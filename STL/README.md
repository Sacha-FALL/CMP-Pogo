# CMP Pogo — STL Files

The final printable STL models have not been uploaded yet.

This directory will contain:

- `Base.stl` — main pogo-pin positioning holder
- `Case.stl` — Raspberry Pi Pico mounting bracket
- `Wase.stl` — support spacer (the physical kit includes eight)

Please wait for the official STL files before attempting to print the jig. The files will be provided under the project license, CC BY-NC-ND 4.0.
