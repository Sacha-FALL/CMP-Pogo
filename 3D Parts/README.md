# CMP Pogo — 3D Parts

The final printable STL models have not been uploaded yet.

This directory will contain:

- `Base.stl` — main pogo-pin positioning holder
- `Case.stl` — Raspberry Pi Pico mounting bracket
- `Wase.stl` — support spacer (the physical kit includes eight)

Please wait for the official STL files before attempting to print the jig. `Base.stl` and `Wase.stl` will be provided under the project license, CC BY-NC-ND 4.0.

`Case.stl` is based on the [Raspberry Pi Pico Case](https://www.printables.com/model/143745-raspberry-pi-pico-case) by **GrevTech**, licensed under [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/), and has been modified for CMP Pogo.
